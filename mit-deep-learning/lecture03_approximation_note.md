## 0. ⭐⭐ 先搞清楚：這一整套在回答什麼問題

【課堂】Bernstein 開場丟出的問題，也是整堂課的軸線：

> **「你會想把神經網路變**寬**，還是變**深**？」**

【Q&A】有人喊「深」。反問為什麼 → 「因為叫做 *deep* learning。」→ 講者：**「所以其實根本不清楚，對吧？這種問題你要怎麼回答？」**

### 0.1 ⭐⭐ 拼圖的三塊

【課堂】機器學習像一塊拼圖，要三塊都拼上才算解決問題：

| 拼圖塊 | 在問什麼 |
|---|---|
| **1. Approximation（逼近）** | 我的模型家族裡**存不存在**一個網路能擬合資料？ |
| **2. Optimization（最佳化）** | 假設存在，我**找不找得到**它？ |
| **3. Generalization（泛化）** | 假設找到了，它在**沒看過的資料**上表現好嗎？ |

> **這一整份筆記只在講第 1 塊。**這點非常重要——後面所有結論的限制都來自這裡。

## 1. 【課堂】暖身：兩個動機問題

### 1.1 一層網路擬合不了什麼

資料是二維、兩類、**線性不可分**。模型是 $\mathrm{ReLU}(W^\top x + b)$。能擬合嗎？

【Q&A】學生答**不行**，理由很漂亮：

> 「只有一個由 $W^\top x$ 定義的超平面，而 **ReLU 不會扭曲那個超平面的形狀**，它只是對輸出施加一個非線性。所以這本質上就是個線性分離器。」

**兩層**就可以了（Lecture 1 已經看過金字塔的直覺）。

### 1.2 ⭐ Weierstrass 函數

【課堂】講者秀出一個**處處連續、處處不可微**的分形函數（遞迴定義、自相似，放大任一段都長得像整體），然後問：**神經網路擬合得了嗎？**

**講者自己的答案**：**「老實說我不知道。我猜是『也許』。」**

⭐ 【課堂】順手給了一個 **final project 點子**：

## 2. ⭐ 把「逼近」講清楚

### 2.1 形式化

三個東西：

| 符號 | 是什麼 | 誰決定 |
|---|---|---|
| $\mathcal{G}$ | **我們想逼近的函數族** | **我們自己挑**（可以挑掉 Weierstrass 函數，可以要求可微…） |
| $\mathcal{F}$ | **神經網路家族** | 由**架構**決定（例如「五層 MLP」） |
| $\epsilon$ | 容許誤差 | 我們挑 |

**問題**：對 $\mathcal{G}$ 裡任何 $g$，是否存在 $f \in \mathcal{F}$ 使誤差 $< \epsilon$？

### 2.2 兩種誤差度量

| 名稱 | 定義 | 直覺 |
|---|---|---|
| **$L_\infty$** | $\displaystyle\sup_x \|f(x) - g(x)\|$ | **輸入空間上任何一點的最大落差** |
| **$L_1$** | $\displaystyle\int \|f(x) - g(x)\|\,\mathrm{d}x$ | 把所有落差**積分加總** |

⭐【DLT §5 Remark 5.4】兩者的**用途是相反的**，這點很值得記：

> **要證「逼近得好」（上界）時，用 $L_\infty$ 或 $L_2$ 比較強。**
> **要證「逼近得爛」（下界）時，用 $L_1$**——因為你要論證**有一大片區域失敗**，而不只是幾個點失敗。

### 2.3 ⭐ Lipschitz 連續

本講挑的函數族 $\mathcal{G}$ 是 **L-Lipschitz 函數**。

$$|g(x + \Delta x) - g(x)| \leq L \cdot |\Delta x|$$

【Q&A】講者引導出的直覺：

> 「把 $\Delta x \to 0$，這看起來像什麼？」→ **「斜率永遠小於某個常數。」** → **「完全正確。這裡面藏著導數的定義。Lipschitz 連續是『導數有界』的一種推廣。」**

**圖像直覺**：在任一點畫兩條線 $y = \pm L x$，形成一個**蝴蝶結（bow tie）／錐形**——**函數在每一點都必須落在那個蝴蝶結裡面**。想像把那個蝴蝶結沿著函數平移。

### 2.4 ⭐ 推廣到多維：RMS norm

$g: \mathbb{R}^d \to \mathbb{R}$ 時，右邊的 $|\Delta x|$ 得換成向量的**範數**。講者挑了他自己偏好的：

$$\|x\|_{\mathrm{RMS}} := \sqrt{\frac{1}{d}\sum_{i=1}^d x_i^2} = \frac{1}{\sqrt{d}}\|x\|_2$$

⭐【課堂】為什麼用它而不是歐氏範數：

> **「歐氏範數是個有量綱的東西。RMS norm 可以想成它的無量綱版本——如果向量每個元素都是 1，RMS norm 就是 1，而歐氏範數會是 $\sqrt{d}$。」**

## 3. ⭐⭐ 課堂版定理：三層 ReLU 網路的萬能逼近

### 3.1 定理敘述

> 設 $g: [0,1]^d \to \mathbb{R}$ 是 **L-Lipschitz**。給定 $\epsilon > 0$，則存在一個**三層 ReLU 網路** $f$，神經元總數
> $$N = 4d\left(\frac{L}{\epsilon}\right)^{d}$$
> 使得 $\displaystyle\int_{[0,1]^d} |f(x) - g(x)|\,\mathrm{d}x \leq 2\epsilon$。

【Q&A】幾個澄清：

| 問題 | 答案 |
|---|---|
| $[0,1]^d$ 是什麼？ | 實數線上 $[0,1]$ 這個區間，在 d 個維度都取它 → **超立方體** |
| N 是每層還是總數？ | **總數**（不過因為只有三層，理解時當成 1 也沒差） |
| 「三層」精確指什麼？ | **三個權重矩陣**，前兩個後面各接一個 ReLU，**第三個後面沒有** |
| 能不能平移/縮放區間？ | 可以，只是會改到 Lipschitz 常數之類的數字 |
| 假設資料在超立方體裡實際嗎？ | ⭐ **相當實際**——實務上你本來就會把輸入正規化到座標尺度約為 1 |

⭐【Q&A】**講者自己對這個定理的態度非常誠實**：

> **「我不是在宣稱這是個重要的結果。我只是說這是一個你可以完整看到證明的例子，然後我們再來想它到底重不重要。」**

### 3.2 ⭐⭐ 證明的三步驟策略

```
Step 1：先假裝輸入是一維，先忘掉神經網路 —— 用「矩形」堆出函數
Step 2：把矩形構造推廣到多維 —— 超矩形（hyper-rectangle）
Step 3：證明一個「兩層 ReLU 網路」可以逼近一個超矩形
        → 再用第三層把所有矩形線性組合起來
```

### 3.3 Step 1：一維，n 個矩形

寫成 $f(x) = \sum_i \alpha_i \mathbb{1}_i(x)$，其中 $\alpha_i$ 是第 i 個矩形的**高度**，$\mathbb{1}_i$ 是**指示函數**（輸入落在該區間就是 1，否則 0）。

⭐【Q&A】有學生誤讀成區間寬度 → 講者澄清：**「那是 indicator，不是 interval。給定一個輸入，只有一個 indicator 會被觸發，然後被它的高度縮放。這是一堆項的和，但任何時候只有一項是 active 的。」**

**誤差怎麼算？**（講者反問全班，學生答對）：**用三角形的面積。**

| 量 | 值 |
|---|---|
| 每個矩形的寬 | $1/n$ |
| 三角形的最大高 | $L \cdot \frac{1}{n}$（Lipschitz 條件） |
| 每個三角形面積 | $\frac{1}{2}\cdot\frac{1}{n}\cdot\frac{L}{n} = \frac{L}{2n^2}$ |
| **總誤差（$L_1$）** | $n \times \frac{L}{2n^2} = \boxed{\dfrac{L}{2n}}$ |

**反解**：要達到誤差 $\epsilon$，需要

$$n \geq \frac{L}{2\epsilon} \quad\Longrightarrow\quad \text{取 } n \geq \frac{L}{\epsilon} \text{ 即可（丟掉常數 } \tfrac12\text{）}$$

### 3.4 Step 2：多維 → 超矩形

完全一樣的計算，只是三角形換成它的高維推廣：

| 量 | 值 |
|---|---|
| 超矩形頂面的面積 | $1/n$（因為 n 個加起來要等於 1） |
| 誤差帽（error cap）的最大高 | 由 Lipschitz 常數決定 |
| **需要的超矩形數量** | $\boxed{n = \left(\dfrac{L}{\epsilon}\right)^{d}}$ |

⭐ **維數詛咒（curse of dimensionality）就在這裡出現了**——指數在 $d$ 上。

【Q&A】學生直接問「$(1/\epsilon)^d$ 這個看起來很嚴重，能不能更好？」→ 講者：

> **「有更多關於問題結構的知識，應該可以好很多。我不是在宣稱這是有趣的結果……你把 Lipschitz 常數升到維度次方，那可能是天文數字。實務上我們永遠不會想這樣做。」**

### 3.5 ⭐ Step 3a：4 個 ReLU 疊出一個矩形

【課堂】講者當場切到繪圖軟體（Desmos 之類）現場示範，這段建議自己動手做一次：

```
1. 先畫 ReLU(x)                      → 一條斜坡
2. 減去 ReLU(x−1)                    → 頂端被壓平
3. 再減一個 ReLU                     → 開始往下彎
4. 再加一個 ReLU                     → 底部也壓平  ⇒ 得到一個梯形
5. 插入常數 C 把所有斜率變陡          → 但形狀被擠在一起
6. 把它們平移回去                     → 變回想要的位置
7. 讓 C 變大（例如 1000）             → 梯形收斂成矩形
```

⭐ **這技術上就是一個兩層網路。**（【課堂】講者順帶說：「這種操作在作業題上大概蠻有幫助的，我真心推薦。」）

### 3.6 ⭐⭐ Step 3b：從矩形到超矩形——一個漂亮的技巧

d 維怎麼辦？**不是**直接做 d 維的東西，而是：

1. 取 **d 個軸對齊的「板（slab）」**，第 j 個只在 $x_j \in [a_j, b_j]$ 時等於 1
2. **把它們相加**：在兩板交會處高度是 2，只有一板 on 的地方是 1 → 得到一個**十字形**的曲面
3. **減掉 $(d-1)$**：整個曲面往下沉，只剩**全部都 on 的那塊**還在 0 以上
4. **套一個 ReLU**：把負的部分切掉

$$g_\gamma(x) = \sigma\!\left(\sum_{j=1}^{d} g_{\gamma,j}(x_j) - (d-1)\right)$$

> ⭐⭐ **這正是 DLT §2.1 Theorem 2.1 用的同一個構造**（見 §4.2）。Telgarsky 在那裡特別註記：**「第二個隱藏層在這裡是關鍵；沒有它，我不清楚怎麼用 $\mathcal{O}(d)$ 個節點做到。」**

### 3.7 神經元怎麼數出 $4d(L/\epsilon)^d$

| 層次 | 數量 |
|---|---|
| 一個一維矩形 | **4** 個神經元 |
| 一個超矩形（對 d 個維度求和） | $4d$ |
| 超矩形的總數 | $(L/\epsilon)^d$ |
| **總計** | $\boxed{4d\left(\frac{L}{\epsilon}\right)^d}$ |

（【課堂】講者：「希望是對的，我昨天才算的常數。」）

### 3.8 ⭐⭐ 這個構造的三個問題（講者自己指出）

| 問題 | 說明 |
|---|---|
| **1. $C \to \infty$ 很可疑** | 【課堂】**「通常你不會希望權重爆掉。那是你的神經網路出問題的徵兆。」** |
| **2. 為什麼不直接用矩形當基底？** | 如果 ReLU 只是拿來近似矩形，那我一開始就用矩形不就好了？ |
| **3. ⭐⭐ 泛化會很慘** | 想像用這組矩形基底去 fit 資料：**每看到一個資料點，只有它正下方那個矩形會被拉動，其他矩形永遠不動。**視覺上顯然應該畫一條線穿過去，而不是把每個點下面的柱子拉到那個高度。→ **訓練誤差會非常好，泛化會非常糟。** |

## 4. 【DLT §2.1】民間傳說級的兩個構造

Telgarsky 講義的 §2 是「古典區間」——**只在乎節點數，不在乎權重大小**，而且目標是**最壞情況**：用某個函數空間範數去逼近任意連續函數。

### 4.1 Proposition 2.1：一維、兩層、threshold 節點

> 設 $g: \mathbb{R} \to \mathbb{R}$ 是 $\rho$-Lipschitz。對任何 $\epsilon > 0$，存在一個兩層網路 $f$，用 $\lceil \rho/\epsilon \rceil$ 個 **threshold 節點** $z \mapsto \mathbb{1}[z \geq 0]$，使得 $\sup_{x \in [0,1]} |f(x) - g(x)| \leq \epsilon$。

**構造**（就是「把線分格，該踏就踏」）：令 $m = \lceil \rho/\epsilon\rceil$、$b_i = i\epsilon/\rho$，然後

$$a_0 = g(0), \quad a_i = g(b_i) - g(b_{i-1}), \qquad f(x) = \sum_{i=0}^{m-1} a_i \mathbb{1}[x \geq b_i]$$

也就是**每格記錄一次「函數值的增量」**，telescoping 之後誤差只剩 $\rho \cdot (\epsilon/\rho) = \epsilon$。

⭐ **Remark 2.1 —— 這裡我們損失了東西**：

> **「我們在為『平坦區域』付錢，而平坦區域正是標準網路的專長！**更小心的證明只在**需要時**才踏一步，付出的代價是 **total variation（全變差）**。」

（對照課堂版：課堂版用 $\sup$（$L_\infty$）+ ReLU 得到同樣量級 $L/\epsilon$，思路完全一致。）

### 4.2 Theorem 2.1：多維、三層、ReLU、$L_1$

> 設 $g: \mathbb{R}^d \to \mathbb{R}$ 連續，選 $\delta$ 使得 $\|x - x'\|_\infty \leq \delta \Rightarrow |g(x)-g(x')| \leq \epsilon$。則存在一個**三層 ReLU 網路** $f$，用 $\Omega(1/\delta^d)$ 個 ReLU，滿足 $\int_{[0,1]^d}|f - g| \leq 2\epsilon$。

**證明結構**：

1. **Lemma 2.1**：把 $[0,1]^d$ 切成邊長 $\leq \delta$ 的長方體 $R_1, \ldots, R_N$，取 $\alpha_i = g(x_i)$（$x_i \in R_i$ 任選），則分段常數函數 $h = \sum_i \alpha_i \mathbb{1}_{R_i}$ 滿足 $\sup|g - h| \leq \epsilon$。
2. 用 ReLU 網路 $g_i$ 去近似每個 $\mathbb{1}_{R_i}$，用三角不等式湊出 $2\epsilon$。
3. **每個 $g_i$ 的構造**：對每個座標 $j$ 用**四個 ReLU** 造出一個梯形（$\gamma$ 控制斜邊寬度，扮演課堂版 $C$ 的角色），

$$g_{\gamma,j}(z) = \sigma\!\Big(\tfrac{z-(a_j-\gamma)}{\gamma}\Big) - \sigma\!\Big(\tfrac{z-a_j}{\gamma}\Big) - \sigma\!\Big(\tfrac{z-b_j}{\gamma}\Big) + \sigma\!\Big(\tfrac{z-(b_j+\gamma)}{\gamma}\Big)$$

   然後 $g_\gamma(x) = \sigma\!\big(\sum_j g_{\gamma,j}(x_j) - (d-1)\big)$ ← **和課堂 §3.6 完全同一招**。

⭐ **Remark 2.3 的三個警告**：

| 警告 | 內容 |
|---|---|
| **維數詛咒** | 指數依賴 $d$，而且**下界也是如此**（Luxburg & Bousquet 2004）。⭐ **CIFAR 的 $d = 3072$。** 「這個問題是**逼近任意連續函數**這件事本身固有的，使得它在實務上不相關。」 |
| **權重很大** | 構造出來的權重和 Lipschitz 常數都很大 |
| **非構造性的替代品** | Theorem 2.3（HSW 1989）能控制 $\sup_x$ 且**只用一個 activation 層**，但**證明不是構造性的**，而且想從中取出估計值，前述所有弱點一樣存在 |

⭐ **Remark 2.2 的兩個旁註**：
- 對**有限點集**這題很簡單——投影到隨機直線上，化約成一維。但我們的目標是在**一個分佈上**逼近。
- **不會有那種漂亮定理**說「淺層逼近的複雜度剛好等於前 $\mathcal{O}(d)$ 階導數的某個函數」。⭐ 這正是講義偏愛談一維情形的原因——**一維才有用 total variation 表述的漂亮刻畫**。

## 5. ⭐⭐【DLT §2.2】只用「一個隱藏層」的萬能逼近

### 5.1 為什麼想只用一層

Theorem 2.1 用了**兩個隱藏層**才造出 $\mathbb{1}[x \in \prod_i [a_i, b_i]]$。但如果我們有辦法**近似乘法**，就可以直接寫

$$x \mapsto \prod_i \mathbb{1}[x_i \in [a_i,b_i]] = \mathbb{1}\big[x \in \textstyle\prod_i [a_i,b_i]\big]$$

**只用一個隱藏層做得到嗎？答案是可以。**

### 5.2 定義

> **Definition 2.1**：函數類 $\mathcal{F}$ 在緊緻集 $S$ 上是 **universal approximator**，若對任何連續 $g$ 和 $\epsilon > 0$，存在 $f \in \mathcal{F}$ 使 $\sup_{x\in S}|f(x)-g(x)| \leq \epsilon$。

⭐ **Remark 2.4：緊緻性是必要的。** 講義舉的例子：**試著用有限大小的 ReLU 網路在整個 $\mathbb{R}$ 上逼近 $\sin$**——做不到。

單隱藏層、寬度不限的網路類：

$$\mathcal{F}_{\sigma,d} := \bigcup_{m \geq 0}\Big\{x \mapsto a^\top \sigma(Wx + b)\Big\}$$

⭐ 注意：**$\mathcal{F}_{\sigma,d}$ 就是「單節點網路」在函數空間裡的線性生成空間（linear span）。**

### 5.3 ⭐⭐ cos 的魔法：對乘法封閉

用**積化和差**：$2\cos(y)\cos(z) = \cos(y+z) + \cos(y-z)$，於是

$$\left(\sum_i a_i \cos(w_i^\top x + b_i)\right)\left(\sum_j c_j \cos(u_j^\top x + v_j)\right)$$

展開後**每一項還是 $\cos(\text{線性} + \text{常數})$ 的形式**。所以

$$f, g \in \mathcal{F}_{\cos,d} \ \Longrightarrow\ fg \in \mathcal{F}_{\cos,d}$$

> ⭐⭐ **$\mathcal{F}_{\cos,d}$ 對乘法封閉。**

（$\exp$ 更簡單：$\exp(a^\top x)\exp(b^\top x) = \exp((a+b)^\top x)$。）

### 5.4 ⭐ Stone–Weierstrass 定理

**古典 Weierstrass 定理（1885）**：多項式是萬能逼近器。
**Stone–Weierstrass**：任何**具備多項式部分性質**的函數族也是萬能逼近器。

> **Theorem 2.2（Stone–Weierstrass）**：若 $\mathcal{F}$ 滿足
> 1. 每個 $f \in \mathcal{F}$ **連續**
> 2. 對每個 $x$，存在 $f$ 使 $f(x) \neq 0$（**不處處消失**）
> 3. 對每組 $x \neq x'$，存在 $f$ 使 $f(x) \neq f(x')$（**分離點**）
> 4. $\mathcal{F}$ 對**乘法**與**向量空間運算**封閉（$\mathcal{F}$ 是一個 **algebra**）
>
> 則 $\mathcal{F}$ 是萬能逼近器。

⭐ **Remark 2.5 的幾個要點**：
- 這是個**重型工具**，但拿來快速檢查萬能逼近非常方便
- **證明不是構造性的**，但 $\Omega(1/\epsilon^d)$ 這個大小下界**很自然地到處冒出來**——例如上面「對乘積封閉」的論證，**每多一個維度項數就翻倍（或更多）**
- 條件 2、3 是**必要的**：若所有 $f$ 在某個 $x$ 都是 0，就逼近不了 $g(x) \neq 0$；若分不開兩點，就逼近不了在該兩點取不同值的函數
- Weierstrass 定理本身的證明也很有意思：**Bernstein 的現代標準證法**（取細格 + 一組在格外仍穩定的內插多項式）；**Weierstrass 原始證法**是把目標函數**與高斯做卷積**使其解析

### 5.5 ⭐ 主定理（Hornik, Stinchcombe & White 1989）

> **Theorem 2.3**：若 $\sigma$ 是 **sigmoidal**——連續，且 $\lim_{z\to-\infty}\sigma(z)=0$、$\lim_{z\to+\infty}\sigma(z)=1$——則 $\mathcal{F}_{\sigma,d}$ 是萬能逼近器。

**證明骨架（兩步）**：
1. 用 Lemma 2.2/2.3 先得到 $h \in \mathcal{F}_{\cos,d}$（或 $\mathcal{F}_{\exp,d}$）使誤差 $\leq \epsilon/2$
2. **把每個 $\cos$ 換成 $\mathcal{F}_{\sigma,1}$ 的元素**，讓額外誤差 $\leq \epsilon/2$ ← **不增加深度，只增加寬度**

⭐ **Remark 2.6 的四點**：

| 要點 | 內容 |
|---|---|
| **ReLU 可以嗎？** | 可以：用 $z \mapsto \sigma(z) - \sigma(z-1)$ 造出 sigmoidal 的形狀，再拆節點 |
| **能靠 exp 去掉 bias 嗎？** | 不能。$\exp$ 的證明本身不需 bias，但**用 ReLU 去逼近 exp 又需要 bias** |
| ⭐ **最弱的條件**（Leshno et al. 1993） | **萬能逼近 $\iff$ $\sigma$ 不是多項式** |
| **維數詛咒又回來了** | 仔細追蹤證明會得到 $\Omega(1/\epsilon^d)$，原因就是**展開 d 項乘積** |

### 5.6 其他萬能逼近的證法（Remark 2.7）

| 論文 | 手法 |
|---|---|
| **Cybenko 1989** | 反證：若漏掉某些函數，由對偶性存在帶號測度 $\mu$ 使 $\int\sigma(a^\top x - b)\,\mathrm{d}\mu = 0$ 對所有 $(a,b)$ 成立；用 **Fourier** 推出 $\mu = 0$ |
| **Leshno et al. 1993** | 若 $\sigma$ 非多項式，大致上可以取出**所有階的導數與多項式** |
| ⭐ **Barron 1993** | 用**反 Fourier 表示**造出無限寬網路 —— **可以打敗最壞情況的維數詛咒！**（DLT §3 的主題） |
| **Funahashi 1989** | 也用 Fourier（講義作者自承沒讀） |

## 8. ⭐⭐ Depth Separation：深度真的有用的證據

### 8.1 ⭐ 這類定理的「形狀」

【課堂】講者把 depth separation 結果拆成三個步驟——**這個模板值得背下來**：

```
1. 挑一個函數的「性質」                     （這裡挑：分段線性函數的「折點（kink）」數量）
2. 構造一個「深但小」的網路，它有非常多這個性質
3. 證明：淺網路要有同樣多這個性質，必須有指數多的神經元
```

### 8.2 ReLU 網路是分段線性的

【Q&A】為什麼？學生答：

> 「因為 ReLU 本質上是一個線性函數加一個門檻。你把它們加起來就造出那種形狀，而之前的變換又是線性的，所以只是在扭曲它。」

**嚴謹的做法是拆成保持性質的組合律**（這正好是 DLT Lemma 5.2 的內容）：

- $f, g$ 分段線性 $\Rightarrow f \circ g$ 分段線性
- $f, g$ 分段線性 $\Rightarrow f + g$ 分段線性
- $f$ 分段線性 $\Rightarrow \alpha f$ 分段線性

### 8.3 ⭐⭐ 折點怎麼增長：加法 vs ReLU

| 操作 | 折點怎麼變 | 直覺 |
|---|---|---|
| **相加** $f + g$ | **最多相加** | 折點只可能出現在原本就有折點的位置（1 kink + 2 kinks = 3 kinks） |
| ⭐ **套 ReLU** | **最多加倍** | 每個線性區段最多被切成兩段 |

**遞迴式**：設第 $\ell$ 層是 $\sigma(W x^{(\ell-1)} + b)$，寬度 $n$，定義 $\mathrm{kinks}(\ell)$ 為輸出各座標折點數的最大值，則

$$\mathrm{kinks}(\ell) \leq 2\,n\,\mathrm{kinks}(\ell-1) \qquad\Longrightarrow\qquad \boxed{\mathrm{kinks}(L) \lesssim (2n)^{L}}$$

（**2 來自 ReLU 的加倍，$n$ 來自把 n 個東西加起來**。）

> ⭐⭐ **上界對寬度只是多項式成長，對深度卻是指數成長。**

【課堂】講者當場承認 base case 的細節沒推乾淨（「kinks(0) 應該是 0 還是 1…我們課後再談，但論證的樣子你看得出來」）——**這其實是誠實的教學示範**。

### 8.4 ⭐ 但那只是上界啊

【課堂】講者主動提出這個反駁：

> **「那只是個上界。也許永遠達不到——也許實務上你造一個很深的 ReLU 網路，輸出函數其實很難有很多折點。」**

所以下一步要**給出構造**證明真的達得到 → 就是**三角函數 $G$**（＝ Telgarsky 的 $\Delta$）：

$$G \text{ 是一個三角形；} \quad G \circ G = 2 \text{ 個三角形；}\quad G\circ G\circ G = 4 \text{ 個三角形；}\ \ldots$$

### 8.5 ⭐⭐ 具體數字（就是這個數字最有說服力）

【課堂】把三角函數**自我複合 500 次**：

| 量 | 值 |
|---|---|
| 折點數 | $\approx 2^{500}$ |
| 每個 $G$ 是 2 層 → 網路深度 | **約 1000 層 MLP** |
| ⭐ **一個三層 MLP 要多寬才能擬合同一個函數？** | **約 $10^{50}$** |

> 【課堂】**「這就是 depth separation 的重點。有一個函數，寫下來甚至不難——就只是一個三角形，自我複合很多次——但如果你想要淺網路精確逼近它，它得非常非常非常寬。」**

⭐ 【課堂】順帶爆雷：**「這也在第一份 problem set 上。這算是來上課的獎勵。」**

### 8.6 ⭐ 這**沒有**說什麼

【課堂】講者立刻收斂：

> 「depth separation 暗示深度可能有巨大優勢，但**它沒有告訴我們深網路好不好訓練**（不談 optimization），**也沒有說深網路在你的資料集上會表現好**（不談 generalization）。**這些純粹是關於逼近的敘述。**」

**還有一個反向的結果**：如果深度那麼好，那我就取寬度 3 一路深下去？→ **不行。有論文證明：若輸入維度是 $d$，你至少需要寬度 $d$ 才能逼近任意函數**（存在最小寬度）。

## 9. ⭐⭐【DLT §5.1–5.2】Telgarsky 的 Δ 函數與嚴格版分離定理

課堂上的三角形，在 Telgarsky 講義裡是主角 **$\Delta$**。

### 9.1 Δ 的定義

$$\Delta(x) = 2\sigma_{\mathrm{r}}(x) - 4\sigma_{\mathrm{r}}(x - \tfrac12) + 2\sigma_{\mathrm{r}}(x-1) = \begin{cases} 2x & x \in [0, \tfrac12) \\ 2 - 2x & x \in [\tfrac12, 1) \\ 0 & \text{otherwise}\end{cases}$$

> **Proposition 5.1**：令 $\langle x \rangle = x - \lfloor x \rfloor$ 為小數部分，則
> $$\Delta^L(x) = \Delta\big(\langle 2^{L-1}x\rangle\big)$$

⭐ 意思是：**$\Delta^L$ 就是 $2^{L-1}$ 份**一模一樣、均勻縮小的 $\Delta$ 副本。

⭐⭐ **「一模一樣」這件事後面會非常關鍵**——不只要多，還要**均勻分佈、不能擠在一起**。

### 9.2 Δ 的用途（Remark 5.1）

| 用途 | |
|---|---|
| **複製輸入** | $\Delta^L$ 造出輸入的 $2^L$ 份（正向與反向）副本 |
| **超立方體上的 parity** | $d = 2^L$ 時，$\prod_i x_i = \Delta^{L-1}\!\big(\frac{d + \sum_i x_i}{2d}\big)$ |
| **造乘法** $(x,y)\mapsto xy$ | 見 §10 |
| ⭐ **Digit extraction（取位數）** | 「在深度網路的上下界裡到處出現」；也出現在 Siegelmann & Sontag 1994 證明 RNN 是圖靈完備的構造裡 |

⭐ **Remark 5.2**：講義作者自承不確定該引誰。「$\Delta^L$ 很像動力系統裡 **logistic map 的迭代**，那至少 1940 年代就被研究了。」

### 9.3 ⭐⭐ Theorem 5.1（Telgarsky 2015, 2016）

> 對任何 $L \geq 2$，函數 $f = \Delta^{L^2+2}$ 是一個有 $3L^2+6$ 個節點、$2L^2+4$ 層的 ReLU 網路，
> **但任何**節點數 $\leq 2^L$ 且層數 $\leq L$ 的 ReLU 網路 $g$ 都逼近不了它：
> $$\int_{[0,1]} |f(x) - g(x)|\,\mathrm{d}x \geq \frac{1}{32}$$

⭐ **這是史上第一個證明「深網路無法被合理大小的淺網路逼近」的結果。**（先前 Bengio & Delalleau 2011 對 sum-product network 有**精確表示**的分離，但那是多項式，推不出 ReLU 的分離。）

### 9.4 ⭐ 為什麼用 $L_1$、為什麼需要「均勻」

**Remark 5.4** 把兩件事講得很清楚：

1. **為什麼 $L_1$**：要論證**有一大片區域失敗**，不能只是幾個點。
2. ⭐⭐ **為什麼需要規律間距**：
   > **「如果我們把 $\Delta$ 換成長得很像的 $4x(1-x)$，這個證明的 $\frac{1}{32}$ 就得換成一個隨 $L$ 遞減的東西。」**
   （因為 logistic map 的迭代**不是**均勻的，副本會擠在一起。）

### 9.5 ⭐⭐ 分段線性片數的組合律（Lemma 5.2）

定義 $N_A(f)$ = 讓 $f$ 在每片上都是仿射的最小分割數。

| 規則 | |
|---|---|
| $N_A(f + g) \leq N_A(f) + N_A(g)$ | 加法：**相加** |
| $N_A(\sum_i a_i g_i + b) \leq \sum_i N_A(g_i)$ | 線性組合：相加 |
| ⭐⭐ $N_A(f \circ g) \leq N_A(f) \cdot N_A(g)$ | **複合：相乘！** |
| $N_A\big(x \mapsto f(\sum_i a_i g_i(x) + b)\big) \leq N_A(f)\sum_i N_A(g_i)$ | 前兩者的結合 |

> ⭐⭐ **Remark 5.7：「這立刻暗示了『複合的威力』——我們是以乘法而非加法在增加複雜度！」**

**Remark 5.9** 補了一個重要限制：**複合律很難達到緊致**——$g$ 的每一片的**像**都必須打到 $f$ 的所有區間才行。**這正是 $\Delta$ 被設計出來的動機：它每次複合幾乎都達到這個上界。**

### 9.6 Lemma 5.1：淺網路的片數上界

> 設 $f$ 是 $L$ 層、各層寬 $(m_1, \ldots, m_L)$、$m = \sum_i m_i$ 的 ReLU 網路。則
> - 第 $i$ 層某節點的輸出 $g$ 滿足 $N_A(g) \leq 2^i \prod_{j<i} m_j$
> - $$N_A(f) \leq \left(\frac{2m}{L}\right)^{L}$$

（第二式從第一式用 **AM–GM** 得到：$\prod_j m_j \leq (m/L)^L$。）

> ⭐ 這**就是課堂 §8.3 的 $(2n)^L$**，只是記帳方式不同。**對寬度多項式、對深度指數。**

⭐ **Remark 5.6**：「用 ReLU 真的讓這個推論簡單很多！」

### 9.7 ⭐⭐ 實務上真的會達到嗎？（Remark 5.8）

> **「很自然也很重要地會想問這個指數成長在實務上是否被實現。初步的工作顯示，至少在初始化附近，有效的片數要小得多。」**（Hanin & Rolnick 2019）

⭐ 這是整份講義裡最該記住的警語之一——**理論上界 ≠ 實際發生**。

### 9.8 證明的第三步：數三角形

在 $y = 1/2$ 畫一條水平線，看它怎麼切 $f = \Delta^{L^2+2}$：

| 量 | 值 |
|---|---|
| $\Delta$ 的副本數 | $2^{L^2+1}$ |
| （半）三角形數 | $2^{L^2+2} - 1$（每份 $\Delta$ 給兩個，邊界損失一個） |
| 每個三角形面積 | $\frac14 \cdot \frac{1}{2^{L^2+2}} = 2^{-L^2-4}$ |
| $g$ 的片數 | $N_A(g) \leq (2\cdot 2^L/L)^L \leq 2^{L^2}$ |

$g$ 每一片最多「消滅」常數個三角形，剩下的三角形面積加總就是 $\int|f-g|$ 的下界：

$$\int_{[0,1]}|f-g| \geq \tfrac12\big[2^{L^2+2} - 1 - 2\cdot 2^{L^2}\big]\cdot 2^{-L^2-4} \geq \frac{1}{32}$$

### 9.9 其他分離結果（Remark 5.10）

| 結果 | 內容 |
|---|---|
| ⭐ **Eldan & Shamir 2015** | 在 $\mathbb{R}^d$ 上，存在 $\mathrm{poly}(d)$ 節點的 **2 隱藏層** ReLU 網路，**1 隱藏層**要 $\geq 2^d$ 節點才逼近得了 |
| **為什麼難** | 那個函數**近似徑向（radial）**；徑向函數的 $\int\|w\|\cdot|\hat f(w)|\,\mathrm{d}w$ 通常在維度上是指數的 |
| **Daniely 2017** | 若額外要求**權重是次指數大小**，有一個乾淨很多的證明 |
| ⭐ **Vardi & Shamir 2020** | 近期證據顯示，**分離「常數深度之間」是困難的**——可以化約到某些複雜度理論問題 |

## 10. ⭐【DLT §5.3】用深度逼近 x²：真正實用的那個

### 10.1 為什麼是 $x^2$

| 問題 | 答案 |
|---|---|
| **為什麼它應該簡單？** | 因為 $x^2 = \int_0^\infty 2\sigma(x - b)\,\mathrm{d}b$ —— **只要均勻擺放 ReLU 就好** |
| ⭐⭐ **好在哪？**（Yarotsky 2016） | 只需要 $\mathrm{poly\,log}(1/\epsilon)$ 的節點數與深度就能達到 $\epsilon$ 精度 |
| **對比** | 前面的淺層一維逼近定理需要 $1/\epsilon$ 個節點 |
| ⭐⭐ **為什麼在乎？** | 有了 $x^2$，**極化恆等式**就給你乘法：$xy = \frac12\big((x+y)^2 - x^2 - y^2\big)$ → 單項式 → 多項式 → **Taylor 展開** |

### 10.2 ⭐⭐ 構造：又是 Δ

令 $S_i = \{0, \frac{1}{2^i}, \ldots, \frac{2^i}{2^i}\}$，$h_i$ 是 $x^2$ 在 $S_i$ 上的**線性內插**。

**關鍵計算**：對 $x \in S_{i+1}\setminus S_i$，令 $\epsilon = 2^{-i-1}$，

$$h_i(x) - h_{i+1}(x) = \tfrac12\big((x-\epsilon)^2 + (x+\epsilon)^2\big) - x^2 = \epsilon^2$$

> ⭐⭐ **關鍵點：這個差跟 $x$ 完全無關！**

而「在 $S_{i+1}\setminus S_i$ 上是 1、其他格點是 0」的線性內插**正是 $\Delta^{i+1}$**。所以

$$h_{i+1} = h_i - \frac{\Delta^{i+1}}{4^{i+1}} \qquad\Longrightarrow\qquad \boxed{h_i(x) = x - \sum_{j=1}^{i}\frac{\Delta^j(x)}{4^j}}$$

### 10.3 Theorem 5.2

> - $h_i$ 是 $x^2$ 在 $[0,1]$ 上、內插點為 $S_i$ 的分段仿射內插
> - $h_i$ 可寫成 **$2i$ 層、$3i$ 個節點**（用 **skip connection**，ResNet 意義下）的 ReLU 網路；或**純 ReLU 網路 $2i$ 層、$4i$ 節點**
> - $\displaystyle\sup_{x\in[0,1]}|h_i(x) - x^2| \leq 4^{-i-1}$
> - **下界**：任何 $\leq L$ 層、$\leq N$ 節點的 ReLU 網路 $f$ 滿足
>   $$\int_{[0,1]}(f(x)-x^2)^2\,\mathrm{d}x \geq \frac{1}{5760\,(2N/L)^{4L}}$$

⭐ **節點數為什麼是 $3i$ 而不是 $\mathcal{O}(i^2)$**：因為 $\Delta^j$ 的元件可以**跨次方重複使用**——這正是 skip connection 出現的原因（或者每層多一個節點來累積輸出）。

⭐ **Remark 5.12**：可以解讀成 **「若想要 $\mathcal{O}(\ln(1/\epsilon))$ 的大小，$\mathcal{O}(\ln(1/\epsilon))$ 層既必要也充分。」**

⭐ **Remark 5.11（歷史）**：$x^2$ 能被高效逼近這件事**幾乎是同時被幾組人發現的**——Yarotsky 2016、Safran & Shamir 2016（平行）、Rolnick & Tegmark 2017（稍晚），各自觀點與證法不同。

### 10.4 從 $x^2$ 還能得到什麼

（全都維持 $\mathcal{O}(\ln(1/\epsilon))$ 的深度與大小）

- **乘法**（極化）
- **多項式**
- **$1/x$ 與有理函數**（Telgarsky 2017）
- **Sobolev 空間裡的函數**（Taylor 展開良好的函數）——這個**需要比 $\ln\frac1\epsilon$ 更大的規模**

## 11. 【DLT §5.4】Sobolev ball：把 x² 推到底

### 11.1 兩個核心零件

| 零件 | 內容 |
|---|---|
| **1. 局部 Taylor 展開** | Sobolev 空間裡的函數**在局部**被 Taylor 展開逼近得很好 → 需要把 $x^2$ 的逼近推廣到**一般單項式** |
| ⭐ **2. Partition of unity（單位分解）** | Taylor 展開只在局部有效，所以需要一個**在 $[0,1]^d$ 不同區域之間平滑切換**的機制。**這是 Yarotsky 2016 除了 $x^2$ 之外另一個非常有趣的想法。** |

### 11.2 三個引理（逐級搭建）

| 引理 | 造出什麼 | 規模 | 誤差 |
|---|---|---|---|
| **Lemma 5.3** `prod_{k,l}` | $l$ 個數的乘積 | $\mathcal{O}(kl)$ 層、$\mathcal{O}(kl+l^2)$ 節點 | $\leq l\cdot 4^{-k}$ |
| **Lemma 5.4** `mono_{k,r}` | 所有 $\leq r$ 次的單項式（$N \leq d^r$ 個） | $\mathcal{O}(kr)$ 層、$\mathcal{O}(d^r(kr+r^2))$ 節點 | $\leq r\cdot 4^{-k}$ |
| **Lemma 5.5** `part_{k,s}` | 近似單位分解 | $\mathcal{O}(kd)$ 層、$\mathcal{O}((kd+d^2)s^d)$ 節點 | $\|\sum_v \text{part}_v - 1\| \leq d2^d4^{-k}$ |

`prod` 的做法就是極化：$\text{prod}_{k,2}(a,b) = \frac12\big(4h_k(\frac{a+b}{2}) - h_k(a) - h_k(b)\big)$，然後遞迴 $\text{prod}_{k,i} = \text{prod}_{k,2}(\text{prod}_{k,i-1}, x_i)$。

`part` 的做法：先用**三個 ReLU** 造一維帽子函數 $h(a) = \sigma(sa+1) - 2\sigma(sa) + \sigma(sa-1)$，再用 `prod` 把 d 個座標的帽子乘起來。

### 11.3 主定理與組裝

$$f(x) := \sum_{v \in S} \text{prod}_{k,2}\big(f_v(x),\ \text{part}_{k,s}(x)_v\big)$$

其中 $f_v$ 是在格點 $v$ 的 Taylor 展開（用 `mono` 逼近）。也就是：**每個局部 Taylor 展開 × 對應的局部帽子，再全部加起來**。

**Theorem 5.3（sketch, Yarotsky 2016 / Schmidt-Hieber 2017）**：若 $f: \mathbb{R}^d \to \mathbb{R}$ 到 $r$ 階的所有偏導都落在 $[-1,+1]$，則存在

$$\widetilde{\mathcal{O}}(\ln(1/\epsilon)) \text{ 層}, \qquad \widetilde{\mathcal{O}}(\epsilon^{-d/r}) \text{ 寬}$$

的網路使 $\sup_{x \in [0,1]^d}|f - g| \leq \epsilon$。

> ⭐ **注意 $\epsilon^{-d/r}$：維數詛咒還在，但被「光滑度 $r$」除掉了。** 函數越光滑，維數的傷害越小。

⭐ **一個可愛的細節**：講義在 Theorem 5.4 旁邊留著作者給自己的便條——**「Matus 給 Matus 的備註：Yarotsky 得到的寬度是 $c(d,r)\ln(1/\epsilon)/\epsilon^{d/r}$，我的比較差，需要追查差異在哪。」** 以及「剛意識到輸入可能出現負值」、「`prod` 的輸入可能超過 1，最懶的修法是把輸入 clip 掉」。**這是一份活的講義，作者把未整平的地方誠實留在上面。**

**Remark 5.14**：這是活躍領域。Schmidt-Hieber 2017 的重證還帶出有趣的迴歸推論；Montanelli, Yang & Du 2020 調整函數類以減輕（仍然很糟的）維度依賴。⭐ **但這些方法全都在用多項式，而「多項式是否準確反映 ReLU 網路的逼近能力」並不清楚**（Telgarsky 2017）。

## 12. ⭐ 實務面：Scaling laws 怎麼說

【課堂】最後 15 分鐘從理論切到實務。

### 12.1 現實世界裡三塊拼圖是糾纏的

> 「訓練出問題時，**你不知道是因為網路根本逼近不了，還是因為訓練失敗。**」
> ⭐ **「有趣的是，『泛化』反而比較好診斷——你算 training error 和 test error，看它們有沒有差。」**

### 12.2 Kaplan et al. 2020（Scaling Laws）

【課堂】「這張圖有人做成 T 恤。」

- x 軸：算力（FLOPs）、資料集大小、參數量；y 軸：test loss
- 三個軸怎麼 scale，**loss 都在往下掉**
- ⭐ 講者的物理直覺：**「loss 不可能永遠往下掉，因為它不能是負的。所以總會飽和。」**

⭐⭐ **但這篇論文最相關的發現是**：

> **它把表現對「參數量」作圖，不是對寬度、也不是對深度。論文主張：在好幾個數量級的範圍內，你把算力預算怎麼分配給寬度和深度並不重要。重要的只有參數量與 FLOPs。**
>
> 深度 20 或深度 10 配上相應的寬度，**沒差**。扣掉 embedding 參數後，**大約深度 6 以上，曲線就互相收斂了**。

### 12.3 ⭐⭐ Confounders（混淆因素）

【課堂】然後講者立刻用 **Chinchilla** 那篇打自己的臉：

> 「他們質疑前一篇的一些結果。其中一個發現是：**如果你用不同的 learning rate schedule，你會得到質性上不同的結論。**」

⭐ **這是整堂課最重要的實務教訓**：

> **「你可能有一組實驗設定說『寬深沒差』，然後你改了訓練的某個細節，突然變成『寬度好很多，因為我修好了那個問題』。我會把那叫做 confounding issue——訓練管線裡某個我們還不完全理解、但會影響結果的面向。」**
>
> **「用實驗解決這些問題非常難（confounding variable 太多），用理論解決也非常難。很多問題還沒解，就是因為它們本來就很難搞清楚。」**

### 13.1 總結

| | 結論 |
|---|---|
| **上半場** | 夠寬的**三層 MLP 可以擬合相當廣的函數類裡的任何函數** |
| **下半場** | **深網路能用少非常多的神經元擬合某些函數**（因為 compositionality）——**depth separation** |
| ⭐ **整體訊息** | **「這些結果有多重要並不清楚，它們和 optimization、generalization 怎麼互動也不清楚。但它們仍然很有趣，值得放進你的工具箱。」** |

### 13.2 ⭐ 預告：為什麼不是所有問題都丟 MLP？

【課堂】思想實驗：一個語音問題、一個影像分類問題，兩個都把資料**攤平成向量**丟給 MLP。MLP 是萬能逼近器，所以這是好主意嗎？

【Q&A】學生給了三個反對理由，一個比一個好：

1. **「它存在，但你不一定找得到。」**（optimization）
2. **「可能沒效率——可能有更適合這種資料的架構。」**
3. ⭐⭐ **「MLP 沒有利用輸入資料的結構。影像有天生的二維結構，波形有天生的序列結構。」**

⭐ 講者接著自問自答了一個很好的反駁：

> 「我寫投影片時也這麼想，然後我想『等等，可是我們現在什麼東西都丟 transformer 啊，這不就跟這個論點矛盾？』」
> **「後來想想不矛盾——就算你把 transformer 用在音訊或影像，網路開頭的預處理層是非常不同的。影像有特殊的 2D patch 表示，音訊有它自己的表示。所以就算什麼都丟 transformer，你還是有在依資料調整架構。」**

**留下的問題**：「Transformers are all we need？也許我們不需要對資料建模——但我覺得**你還是得對資料建一點模**。而且 transformer 有多吃資料？也許存在一個更好的模型家族，需要少得多的資料就能學會。」

## 14. 一頁速查表

### 14.1 概念

| 概念 | 一句話 |
|---|---|
| ⭐⭐ **拼圖三塊** | **Approximation（存在嗎）／Optimization（找得到嗎）／Generalization（有用嗎）**——本講只講第一塊 |
| **Lipschitz** | $\|g(x+\Delta x)-g(x)\| \leq L\|\Delta x\|$；直覺是**導數有界**，圖像是**蝴蝶結** |
| **RMS norm** | $\frac{1}{\sqrt d}\|x\|_2$ —— 歐氏範數的**無量綱版本** |
| **$L_\infty$ vs $L_1$** | ⭐ **證上界（好）用 $L_\infty$；證下界（爛）用 $L_1$**——因為要論證「一大片區域」都失敗 |
| **Universal approximator** | 在**緊緻集**上，對任何連續函數都能以任意精度逼近。**緊緻性必要**（有限網路逼近不了整個 $\mathbb{R}$ 上的 sin） |

### 14.2 逼近的正面結果

| 結果 | 內容 |
|---|---|
| **課堂定理** | L-Lipschitz $g:[0,1]^d\to\mathbb{R}$，**三層 ReLU**、$4d(L/\epsilon)^d$ 神經元，$L_1$ 誤差 $\leq 2\epsilon$ |
| **DLT Prop 2.1** | 一維 $\rho$-Lipschitz，**兩層**、$\lceil\rho/\epsilon\rceil$ 個 threshold，$L_\infty$ 誤差 $\leq\epsilon$ |
| **DLT Thm 2.1** | 多維連續，**三層 ReLU**、$\Omega(1/\delta^d)$，$L_1$ 誤差 $\leq 2\epsilon$ |
| ⭐ **DLT Thm 2.3（HSW 89）** | $\sigma$ **sigmoidal** ⟹ **單隱藏層**萬能逼近（非構造性，經 Stone–Weierstrass） |
| **Leshno et al. 93** | ⭐ 最弱條件：**萬能逼近 $\iff$ $\sigma$ 不是多項式** |
| **Barron 93** | 用 Fourier 造無限寬網路，**能打敗最壞情況的維數詛咒** |

### 14.3 ⭐⭐ 三個關鍵構造

| 構造 | 做法 |
|---|---|
| **一維矩形** | **4 個 ReLU** + 一個斜率參數 $C$，$C\to\infty$ 時收斂成矩形 |
| ⭐⭐ **d 維超矩形** | **d 個軸對齊的板相加 → 減 $(d-1)$ → 套 ReLU**（挑出全部交會的那塊）。**第二個隱藏層在這裡是必要的** |
| ⭐⭐ **$\Delta$（三角形）** | $\Delta = 2\sigma(x) - 4\sigma(x-\frac12) + 2\sigma(x-1)$；$\Delta^L = \Delta(\langle 2^{L-1}x\rangle)$ = **$2^{L-1}$ 份均勻的副本** |

### 14.4 ⭐⭐ 深度的好處

| 事實 | 內容 |
|---|---|
| **ReLU 網路是分段線性的** | 性質在 $+$、$\circ$、純量乘法下保持 |
| **加法** | 折點數**相加** |
| **套 ReLU** | 折點數**最多加倍** |
| ⭐⭐ **複合** | $N_A(f\circ g) \leq N_A(f)\cdot N_A(g)$ ——**乘法而非加法** ⟹ **「複合的威力」** |
| ⭐⭐ **主上界** | $N_A(f) \leq (2m/L)^L$ ——**對寬度多項式，對深度指數** |
| **Telgarsky Thm 5.1** | $\Delta^{L^2+2}$（$3L^2+6$ 節點）**無法**被任何 $\leq 2^L$ 節點、$\leq L$ 層的網路逼近到 $L_1 < \frac1{32}$ |
| **課堂的具體數字** | 三角形自我複合 500 次 → **1000 層**；三層 MLP 要 **$10^{50}$ 寬** |
| **Eldan & Shamir 15** | $\mathbb{R}^d$ 上：$\mathrm{poly}(d)$ 的 **2 隱藏層** vs $2^d$ 的 **1 隱藏層**（近似徑向函數） |
| ⭐ **最小寬度** | 輸入維度 $d$ ⟹ **至少要寬度 $d$**，不能只靠深度 |
| ⭐⭐ **實務警告** | **Hanin & Rolnick 2019：至少在初始化附近，有效片數遠小於上界。** |

### 14.5 ⭐ $x^2$ 那條線

| | |
|---|---|
| **為什麼容易** | $x^2 = \int_0^\infty 2\sigma(x-b)\,\mathrm{d}b$ |
| **遞迴式** | $h_i(x) = x - \sum_{j=1}^i \Delta^j(x)/4^j$，關鍵是**每層的修正量與 $x$ 無關** |
| **代價** | $2i$ 層、$3i$ 節點（含 skip connection），誤差 $\leq 4^{-i-1}$ ⟹ **$\mathcal{O}(\ln(1/\epsilon))$** |
| **對照淺層** | 淺層要 **$1/\epsilon$** |
| ⭐⭐ **為什麼重要** | 極化 $xy = \frac12((x+y)^2-x^2-y^2)$ ⟹ 單項式 ⟹ 多項式 ⟹ **Taylor / Sobolev**；還有 $1/x$ 與有理函數 |
| **Sobolev 結果** | $\widetilde{\mathcal{O}}(\ln(1/\epsilon))$ 層、$\widetilde{\mathcal{O}}(\epsilon^{-d/r})$ 寬 ⟹ **函數越光滑（r 越大），維數詛咒越輕** |

### 14.6 ⭐⭐ 態度（最該記住的部分）

| 主張 | 反駁 |
|---|---|
| 「神經網路是萬能逼近器！」 | ⭐ **多項式也是，Python 程式的空間也是。裝了 Python 並不能開始做機器學習。** |
| 「所以三層就夠了」 | ⭐ 但需要**指數多**的神經元（維數詛咒；CIFAR 的 $d = 3072$） |
| 「所以深比較好」 | ⭐ 那只是**上界**；而且**沒說**深網路好訓練，也**沒說**它會泛化 |
| 「Scaling law 說寬深沒差」 | ⭐ **換一個 learning rate schedule 就得到質性不同的結論**——confounder 到處都是 |
| 「那我的架構隨便挑」 | ⭐ **資料的結構還是要建進模型**——就算全部用 transformer，前面的 patch/tokenizer 也是為資料量身打造的 |
