## 1. 中性原子量子電腦

### 1.1 為什麼中性原子變熱門

[▶ 01:00](https://youtu.be/36S3yCY193M?t=60)

- 【口頭】一年前講這門課時中性原子還不流行，現在卻是**領先的方案**，因為它們最先做到超過 1,000 個量子位元。
- 【口頭】一個月前 Atom Computing 發表了約 **1,200 個量子位元**的機器，其中約 1,100 個可用。

⚠️ 逐字稿缺字：字幕把公司名寫成「item Computing」，依上下文（中性原子）應是 **Atom Computing**。

| | 超導 | 中性原子 |
|---|---|---|
| 量子位元 | 要在晶片上**製造** | **原子本身就是量子位元**，不用製造 |
| 擴充 | 難 | 【口頭】地球上原子幾乎無限多，**很容易擴充** |
| 難處 | — | **怎麼控制**它們做運算 |

**控制方式**：[▶ 02:00](https://youtu.be/36S3yCY193M?t=120)

- 原子放在真空腔裡，用雷射從底部、前方、側面控制。
- **SLM（spatial light modulator，空間光調變器）**：製造一個場，把原子**固定住**。
- **AOD（acousto-optic deflector，聲光偏轉器）**：[▶ 03:00](https://youtu.be/36S3yCY193M?t=180) 對原子做操作；移動 2D 的 AOD，原子會**跟著一起移動**。

⚠️ 逐字稿缺字：字幕寫「crystal optic deflector」，依投影片是 **acousto-optic deflector**。

### 1.2 固定原子陣列的限制

[▶ 03:00](https://youtu.be/36S3yCY193M?t=180)

（ISCA 2021、ISCA 2022 的研究）

- 兩個原子做運算時，作用區會**重疊**，影響附近的原子。
- 距離太遠的兩個原子**不能直接互動**（不是全部互相連接）。
- **原子會遺失**：[▶ 04:00](https://youtu.be/36S3yCY193M?t=240) 系統裡的原子可能突然不見了。
- 【口頭】Geyser（ISCA 2022）用**三量子位元**的操作區塊：三量子位元閘表達力比兩量子位元強，能**大幅縮短電路長度**。

### 1.3 可移動的原子陣列：FPQA

[▶ 05:00](https://youtu.be/36S3yCY193M?t=300)

**FPQA = Field Programmable Quantum Array（現場可程式化量子陣列）**：【口頭】類比 FPGA。

| 原子 | 能不能動 | 用途 |
|---|---|---|
| **SLM 原子**（藍色） | 固定 | 放原本的量子位元 |
| **AOD 原子**（黃色） | **可移動**，但只能**整列或整行**一起沿 2D 網格移動 | 搬到別的原子旁邊做運算 |

- 【口頭】[▶ 06:00](https://youtu.be/36S3yCY193M?t=360) 超導晶片上的量子位元和連線都是固定的（上一講的 qubit mapping 問題）；中性原子**能移動**，是很大的自由度。
- 想在左上角和右下角之間做閘，把一個 AOD 原子移過去就好，**不用插一大堆 SWAP**。

**閘的控制**：[▶ 07:00](https://youtu.be/36S3yCY193M?t=420)

| 閘 | 雷射 | 特性 |
|---|---|---|
| **單一量子位元閘** | **Raman 雷射**，垂直於原子平面 | 可以**個別**定址 |
| **兩量子位元閘** | **Rydberg 雷射**，從側面平行照射 | **全域照射**：距離夠近的原子對**全部強制**做閘 |

【口頭】[▶ 08:00](https://youtu.be/36S3yCY193M?t=480) 全域照射的好處：**平行度非常高**，照一次所有閘一起做完。壞處：不能選擇性關掉某個閘，所以不想做閘的原子不能靠太近。

### 1.4 Q-Pilot：用「飛行輔助位元」編譯

[▶ 09:00](https://youtu.be/36S3yCY193M?t=540)

（講者實驗室的方法）

**想法**：演算法和編譯器一起設計。

- 用 CNOT 把原本的量子位元**扇出（fan-out）**到輔助位元（ancilla）上，做出它的「分身（decoy）」。
- [▶ 10:00](https://youtu.be/36S3yCY193M?t=600) 在分身和原本的量子位元之間做閘，**數學上跟原本的電路完全等價**，但減少了原本閘之間的相依性。

**流程**：[▶ 11:00](https://youtu.be/36S3yCY193M?t=660)

1. 把演算法的量子位元映射到**固定的 SLM 原子**。
2. 用**可移動的 AOD 原子**當分身（飛行輔助位元）。
3. 做單一量子位元閘。
4. 移動 AOD 原子到目標旁邊，做兩量子位元閘。
5. [▶ 12:00](https://youtu.be/36S3yCY193M?t=720) **回收**輔助位元（做完要還原，確保功能跟原本一樣）。

```
建立輔助位元 → 做兩量子位元閘 → 回收輔助位元 → 下一層
```

- 【口頭】[▶ 13:00](https://youtu.be/36S3yCY193M?t=780) 很有規律、可擴充：就算 100 個量子位元也照同樣的步驟。**目前唯一能編譯超過 1,000 個量子位元的編譯器**。

**QAOA 的例子（提高平行度）**：[▶ 13:00](https://youtu.be/36S3yCY193M?t=780)

- 12 個節點的圖做 **max-cut**（把圖切成兩半，讓跨越的邊最多）。每條邊是一個兩量子位元閘。
- [▶ 14:00](https://youtu.be/36S3yCY193M?t=840) 用**動態規劃**，每個階段盡量讓最多的閘一起做。
- 【口頭】[▶ 15:00](https://youtu.be/36S3yCY193M?t=900) 第三階段**一次照射就做完 8 對節點的閘**，只有可移動的中性原子陣列做得到。

**結果**：[▶ 16:00](https://youtu.be/36S3yCY193M?t=960)

- 跟超導（IBM Washington）和兩種固定陣列比：兩量子位元閘數和電路深度都減少（長距離閘不用 SWAP，加上 Rydberg 雷射的高平行度）。
- 閘少、深度淺 → 閘錯誤和退相干錯誤都少 → 【口頭】fidelity 大約好 **8%**。
- 【口頭】QuEra 已經把 256 個量子位元的機器放上 **AWS**，可以去玩。

## 2. ⭐⭐ 參數化量子電路（PQC）

### 2.1 量子機器學習的四種組合

[▶ 17:00](https://youtu.be/36S3yCY193M?t=1020)

| | **傳統演算法** | **量子演算法** |
|---|---|---|
| **傳統資料** | **CC**：前 20 講學的 | **CQ**：⭐ 這一講要講的 |
| **量子資料** | **QC**：量子位元控制、校正、讀出…… | **QQ**：用量子機器處理量子資訊 |

- **QC**：[▶ 19:00](https://youtu.be/36S3yCY193M?t=1140) 【口頭】量子記憶體還不成熟，很多實驗（例如偵測宇宙射線、物理量）還是用傳統演算法處理量子感測器的資料。
- **QQ**：【口頭】未來很有前景，**不用在量子和傳統之間轉換**。例如有公司直接用量子位元偵測車輛的加速度，再直接在量子位元上做後處理。未來有量子 RAM（qRAM）後更容易。

【Q&A】[▶ 18:00](https://youtu.be/36S3yCY193M?t=1080) 有學生提問（字幕沒錄到問題），講者回答量子資料的來源：例如物理系的**量子感測器**可以直接接上量子電腦；未來有了量子記憶體（qRAM），就能把資訊存在量子 RAM 裡直接計算。

⚠️ 逐字稿缺字：上面這個 Q&A 的問題本身沒被字幕錄到。

### 2.2 什麼是 PQC

[▶ 20:00](https://youtu.be/36S3yCY193M?t=1200)

**PQC = Parameterized Quantum Circuit**：電路裡有**固定的閘**和**含參數的閘**。

| 閘 | 類型 |
|---|---|
| $R_X(\theta)$、$R_Z(\theta)$ | 含參數：可以轉任意角度 |
| CX（CNOT） | 固定 |
| $CR_X(\theta)$ | 含參數的控制旋轉 |

【口頭】[▶ 21:00](https://youtu.be/36S3yCY193M?t=1260) 跟傳統深度學習很像：深度學習有權重矩陣和設計好的架構（attention、LSTM），用資料和最佳化演算法訓練參數。PQC 也是一樣，只是參數是**旋轉角度**。

### 2.3 表達力（Expressivity）

[▶ 22:00](https://youtu.be/36S3yCY193M?t=1320)

**電路能涵蓋多少希爾伯特空間（Hilbert space）？** 量法：電路產生的狀態分布，跟**均勻分布**差多少。

**例子**：哪個電路表達力比較好？

| 電路 | 閘 | 在 Bloch 球上涵蓋 |
|---|---|---|
| Identity | 不做事 | 一個點 |
| **A** | $H$ → $R_Z(\theta)$ | [▶ 23:00](https://youtu.be/36S3yCY193M?t=1380) **一個圈**（赤道） |
| **B** | $H$ → $R_Z(\theta_1)$ → $R_X(\theta_2)$ | **幾乎整顆球** |
| **U 閘** | 3 個參數 | [▶ 24:00](https://youtu.be/36S3yCY193M?t=1440) 整顆球，而且分布**很均勻** |

- 【口頭】直覺上 B 比較好，因為多一個參數。
- 均勻取樣旋轉角度時，B 的點**有些地方比較密**；U 閘則很均勻。

**量化**：[▶ 25:00](https://youtu.be/36S3yCY193M?t=1500) 跟均勻分布之間的 **KL 散度**，越小表達力越好。

| 電路 | KL 散度 |
|---|---|
| Identity（單一點） | 很高 |
| 中間某個電路 | 約 0.22 |
| U 閘 | **< 0.01** |

⚠️ 待確認：字幕說「0.22」對應的是哪一個電路，聽不太清楚。

### 2.4 糾纏能力（Entanglement capability）

[▶ 25:00](https://youtu.be/36S3yCY193M?t=1500)

- 【口頭】多個量子位元之間如果**沒有任何閘**，就不可能產生糾纏。
- 用 **Meyer-Wallach（MW）量度**：範圍 $[0, 1]$。
  - **0**：沒有糾纏。
  - **1**：完全糾纏。
- 用**平均 MW** 衡量一個電路的糾纏能力。

**結果**（論文裡的 19 種電路）：[▶ 27:00](https://youtu.be/36S3yCY193M?t=1620)

- **電路 1**：量子位元之間沒有閘 → 不管疊幾層都是 **0**。
- [▶ 28:00](https://youtu.be/36S3yCY193M?t=1680) 表現最好的電路結構：**先用 H 製造疊加，再用受控閘製造糾纏**（呼應 [Lecture 21 §4.5](lecture21_quantum_computing_basics_note.md)）。
- **層數越多**，糾纏能力通常越強。

### 2.5 硬體效率

[▶ 29:00](https://youtu.be/36S3yCY193M?t=1740)

設計 PQC 時要考慮：

1. **量子位元的連接**：不然要插很多 SWAP。
2. **是不是原生閘（native gate）**：不同硬體的指令集不同。

【口頭】[▶ 30:00](https://youtu.be/36S3yCY193M?t=1800) 就像設計神經網路時要讓大部分運算可以平行（例如矩陣乘法），GPU 才能加速；量子電路也要針對目標硬體設計。

## 3. ⭐ 把傳統資料編碼進量子位元

[▶ 30:00](https://youtu.be/36S3yCY193M?t=1800)

處理傳統資料時，第一步是把資料**上傳到量子位元**。四種方法：

### 3.1 基底編碼（Basis encoding）

[▶ 30:00](https://youtu.be/36S3yCY193M?t=1800)

- 跟傳統電腦的二進位一樣：$x = 2$ → 二進位 `10` → 做一個**全部能量都在 $|10\rangle$** 的量子態。
- $x = 0$ → $|00\rangle$；$x = 3$ → $|11\rangle$。
- [▶ 31:00](https://youtu.be/36S3yCY193M?t=1860) 只編一個數**很沒效率**。
- 但可以**同時**編很多個數：

$$
x \in \{0, 3\}:\ \frac{1}{\sqrt{2}}\left(|00\rangle + |11\rangle\right),\qquad
x \in \{0, 1, 3\}:\ \frac{1}{\sqrt{3}}\left(|00\rangle + |01\rangle + |11\rangle\right)
$$

- 【口頭】[▶ 32:00](https://youtu.be/36S3yCY193M?t=1920) 還是有限制：2 個量子位元最多 4 個基底狀態。

### 3.2 振幅編碼（Amplitude encoding）

[▶ 32:00](https://youtu.be/36S3yCY193M?t=1920)

- 把數字直接當成**狀態向量的振幅**。
- 例如 $[1, 0, 0, 0]$ → $|00\rangle$；$[0.8, 0.2, 0.6, 0.45]$ → 各基底的振幅（要先正規化，見下面的例子）。
- ⭐ **$N$ 個特徵只要 $\log_2 N$ 個量子位元**。

$$
1000\ \text{個特徵}\ \Rightarrow\ \lceil\log_2 1000\rceil = 10\ \text{個量子位元}\quad(2^{10} = 1024)
$$

- 【口頭】[▶ 34:00](https://youtu.be/36S3yCY193M?t=2040) 例如人類一年產生的資料，大概 70 個量子位元以內就能表示，因為 $2^{70}$ 隨量子位元數指數變大。

**多筆資料接起來**：[▶ 35:00](https://youtu.be/36S3yCY193M?t=2100) $[1.5, 0]$ 和 $[-2, 3]$ 接成 $[1.5, 0, -2, 3]$。

$$
\Vert x\Vert = \sqrt{1.5^2 + 0^2 + (-2)^2 + 3^2} = \sqrt{15.25}
\quad\Rightarrow\quad
|\psi\rangle = \frac{1}{\sqrt{15.25}}\left(1.5|00\rangle - 2|10\rangle + 3|11\rangle\right)
$$

- 前面要乘一個**正規化係數**，讓振幅平方和是 1（[Lecture 21 §2.4](lecture21_quantum_computing_basics_note.md)）。

**為什麼有效率？**[▶ 36:00](https://youtu.be/36S3yCY193M?t=2160) 【口頭】100 個量子位元的狀態向量長度是 $2^{100}$。之後對它做一次運算，數學上等於一個 $2^{100}\times2^{100}$ 的**超大矩陣乘向量**。

### 3.3 角度編碼（Angle encoding）

[▶ 36:00](https://youtu.be/36S3yCY193M?t=2160)

- 把資料當成**旋轉閘的角度**。
- 例如 $[0, \pi/2, \pi]$：三個量子位元各加 $R_Y(0)$、$R_Y(\pi/2)$、$R_Y(\pi)$。

### 3.4 任意編碼（Arbitrary encoding）

[▶ 37:00](https://youtu.be/36S3yCY193M?t=2220)

- 設計任意的 PQC，把輸入資料當作其中的**旋轉角度**。
- 不一定要放在電路最前面，**中間也可以**再編碼。
- 【口頭】[▶ 38:00](https://youtu.be/36S3yCY193M?t=2280) 近期研究在讓**不同輸入產生不同狀態**，做出更好的任意編碼。

## 4. ⭐⭐ 訓練 PQC

### 4.1 整體流程

[▶ 38:00](https://youtu.be/36S3yCY193M?t=2280)

```
參數 θ_n → 量子電路算出 f(θ) → 損失（例如分類的 cross-entropy）→ 更新參數 → θ_{n+1}
```

- 反覆迭代，找讓損失最小的參數。

### 4.2 有限差分梯度（Finite difference）

[▶ 40:00](https://youtu.be/36S3yCY193M?t=2400)

$$
\frac{\partial f}{\partial\theta} \approx \frac{f(\theta + \epsilon) - f(\theta - \epsilon)}{2\epsilon}
$$

| 優點 | 缺點 |
|---|---|
| [▶ 41:00](https://youtu.be/36S3yCY193M?t=2460) **跟函數的結構無關**，連量子 + 傳統混合計算都能用 | **準確度取決於 $\epsilon$**：$\epsilon$ 太大就跟真正的梯度差很多 |

### 4.3 ⭐ Parameter-shift 規則

[▶ 41:00](https://youtu.be/36S3yCY193M?t=2460)

**解析地**算出梯度，不是近似：

$$
\frac{\partial f(\theta)}{\partial\theta} = \frac{1}{2}\left[f\left(\theta + \frac{\pi}{2}\right) - f\left(\theta - \frac{\pi}{2}\right)\right]
$$

**步驟**：[▶ 42:00](https://youtu.be/36S3yCY193M?t=2520)

1. 把 $\theta$ 加 $\pi/2$，在量子電腦上跑一次 → $f(\theta + \pi/2)$。
2. 把 $\theta$ 減 $\pi/2$，再跑一次 → $f(\theta - \pi/2)$。
3. 相減除以 2。

**跟有限差分有什麼不同？**【口頭】看起來很像，但 $\pi/2$ 很大，竟然還是精確的。

**直覺**：[▶ 43:00](https://youtu.be/36S3yCY193M?t=2580) 【口頭】旋轉閘的矩陣裡都是 $\cos$ 和 $\sin$。$\cos$ 的導數是 $-\sin$，而 $\sin$ 就是 $\cos$ 平移 $\pi/2$。

以下**不是逐字稿內容**，是依講者的 $\cos$/$\sin$ 直覺推論的簡單驗證：假設 $f(\theta) = a\cos\theta + b\sin\theta + c$，

$$
\frac{1}{2}\left[f\left(\theta + \frac{\pi}{2}\right) - f\left(\theta - \frac{\pi}{2}\right)\right]
= \frac{1}{2}\left[(-a\sin\theta + b\cos\theta) - (a\sin\theta - b\cos\theta)\right]
= -a\sin\theta + b\cos\theta = f'(\theta)
$$

（用到 $\cos(\theta \pm \frac{\pi}{2}) = \mp\sin\theta$、$\sin(\theta \pm \frac{\pi}{2}) = \pm\cos\theta$。）

【投影片補充】完整證明是把閘寫成指數形式再推導。

⭐ **最重要的好處**：[▶ 44:00](https://youtu.be/36S3yCY193M?t=2640) **完全在量子硬體上算梯度**。

- 每個參數只要**在量子電腦上多跑兩次**。
- 【口頭】[▶ 45:00](https://youtu.be/36S3yCY193M?t=2700) 100 個量子位元的電路，傳統電腦根本模擬不了，但還是能用 parameter-shift 訓練，整個訓練過程**不需要傳統模擬**，很有效率、可擴充。

**驗證**：[▶ 46:00](https://youtu.be/36S3yCY193M?t=2760) 在小電路上跟反向傳播比，兩者算出的梯度**完全一樣**。

**反向傳播**：【投影片補充】也能算梯度（因為全部都是可微的線性代數），但**只能在傳統模擬器上**用。

### 4.4 混合訓練的完整流程

[▶ 46:00](https://youtu.be/36S3yCY193M?t=2760)

1. 在量子電腦上跑（不平移）→ 得到 $f(\theta)$。
2. 繼續往前算（例如 softmax、cross-entropy）→ 得到 Loss。
3. 反向傳播 → $\dfrac{\partial\,\text{Loss}}{\partial f}$。
4. [▶ 47:00](https://youtu.be/36S3yCY193M?t=2820) 平移兩次、在量子電腦上跑 → $\dfrac{\partial f}{\partial\theta_i}$（或用有限差分）。
5. **連鎖律**，把所有路徑加起來：

$$
\frac{\partial\,\text{Loss}}{\partial\theta_i} = \sum_{j}\frac{\partial\,\text{Loss}}{\partial f_j}\cdot\frac{\partial f_j}{\partial\theta_i}
$$

例子有 4 個量子位元 → 4 個輸出 $f_j$ → 4 條路徑。量子電腦上**只需要做前向**。

### 4.5 SPSA：減少在量子電腦上跑的次數

[▶ 48:00](https://youtu.be/36S3yCY193M?t=2880)

**SPSA = Simultaneous Perturbation Stochastic Approximation（同時擾動隨機近似）**

- Parameter-shift：$N$ 個參數要跑 **$2N$ 次**。【口頭】100 萬個參數就要 200 萬次，在現在的機器上可能要花幾百萬美元。
- **SPSA**：[▶ 49:00](https://youtu.be/36S3yCY193M?t=2940) **同時擾動所有參數**，每次迭代**只跑 2 次**。假設是把 $\epsilon$ 很小時，景觀不會變太多。
- 【口頭】[▶ 50:00](https://youtu.be/36S3yCY193M?t=3000) 收斂跟一般梯度下降差不多，但量子電腦上跑的次數少很多。量子自然梯度下降（quantum natural gradient）收斂更快。

### 4.6 貧瘠高原（Barren plateaus）

[▶ 50:00](https://youtu.be/36S3yCY193M?t=3000)

- 量子位元或層數變多時，會出現**梯度消失**。
- [▶ 51:00](https://youtu.be/36S3yCY193M?t=3060) **梯度的變異數隨量子位元數指數下降**。
- 不管深度是線性還是固定，都會大幅下降。
- 【口頭】就像 ResNet 出現之前訓練很深的神經網路，反向傳播時梯度會消失。

## 5. 量子分類器與其他任務

### 5.1 量子神經網路分類器

[▶ 52:00](https://youtu.be/36S3yCY193M?t=3120)

**MNIST 手寫數字分類**：

```
28×28 影像 → 降採樣到 4×4 → 編碼（角度編碼，像素縮放到 [0, 2π]）
          → 可訓練的參數化層 → 在 Z 基底測量 4 個量子位元 → 4 個數字 → softmax / 其他後處理
```

- [▶ 54:00](https://youtu.be/36S3yCY193M?t=3240) 【口頭】測量之後可以接**任何傳統的後處理**（簡單的 softmax，或其他神經網路層），做**量子 + 傳統混合計算**，一起用 parameter-shift 訓練。
- 降採樣到 4×4 後，還是看得出 0 和 1。

### 5.2 VQE 和 QAOA

[▶ 55:00](https://youtu.be/36S3yCY193M?t=3300)

**VQE（Variational Quantum Eigensolver，變分量子特徵值求解器）**：

- **任務**：算分子（例如 CH₄）的**基態能量**。【口頭】這是**藥物開發**最重要的一步：改變原子間的距離算能量，能量最低的就是穩定的鍵長。
- 用 PQC 準備**特徵值最小的特徵態**。
- [▶ 56:00](https://youtu.be/36S3yCY193M?t=3360) 沒有傳統資料輸入。依分子結構把 Hamiltonian 拆成 Pauli 項，各自測量後**加權相加**得到期望值。
- 目標：**最小化**這個期望值（基態就是能量最小的狀態）。
- 【口頭】[▶ 57:00](https://youtu.be/36S3yCY193M?t=3420) 比傳統方法有效率：分子有 100 個原子時，傳統方法（張量縮並）記憶體成本很大；量子只要跑前向。

**QAOA（Quantum Approximate Optimization Algorithm）**：【投影片補充】用 PQC 解組合最佳化問題（例如 §1.4 的 max-cut）。

## 6. ⭐ 雜訊感知的晶片上訓練（QOC）

### 6.1 雜訊讓梯度不可靠

[▶ 57:00](https://youtu.be/36S3yCY193M?t=3420)

- 【口頭】NISQ 機器雜訊很大，直接在量子電腦上訓練可靠嗎？**現在的硬體不太可靠**。
- 【口頭】類比：訓練傳統神經網路時要考慮**對抗攻擊**；量子的「攻擊」是硬體**本身的雜訊**。

[▶ 58:00](https://youtu.be/36S3yCY193M?t=3480)

| 訓練方式 | 結果 |
|---|---|
| 傳統模擬器上訓練和測試（無雜訊） | 準確率穩定上升 |
| 在量子電腦上用 parameter-shift 訓練 | 有上升，但**不穩定**，跟無雜訊差很多 |

### 6.2 關鍵觀察：小梯度的相對誤差很大

[▶ 59:00](https://youtu.be/36S3yCY193M?t=3540)

- 雜訊的大小大致**固定**。
- **梯度大**：雜訊佔的比例小 → 可靠。
- **梯度小**：可能**完全被雜訊蓋過** → 不可靠。
- IBM 的 Santiago、Casablanca 等機器上都看到同樣趨勢：梯度越大，相對誤差越小。

⚠️ 逐字稿缺字：[▶ 1:00:00](https://youtu.be/36S3yCY193M?t=3600) 字幕把 IBM 的機器寫成「San Diego」，投影片是 **Santiago**。

【口頭】IBM 的機器都用地名命名，講者一開始以為 IBM 把機器放在世界各地，其實都在紐約的辦公室。今年初 IBM 第一次把實體機器放到克里夫蘭醫學中心（Cleveland Clinic），擺在用餐區讓大家看。

### 6.3 機率式梯度剪枝（Probabilistic gradient pruning）

[▶ 1:01:00](https://youtu.be/36S3yCY193M?t=3660)

**想法**：

1. 小梯度不可靠 → **凍結**對應的參數，只用可靠的大梯度更新。
2. 如果能**預測**接下來幾步哪些梯度會很小，就**連算都不用算** → 更可靠，也更有效率。

**兩個視窗輪流**：[▶ 1:02:00](https://youtu.be/36S3yCY193M?t=3720)

| 視窗 | 做什麼 |
|---|---|
| **累積視窗（accumulation window）** | 每一步都算所有梯度，**記錄累積的梯度大小** |
| **剪枝視窗（pruning window）** | 把累積的梯度大小**正規化成機率分布**，依機率**跳過**一部分參數的梯度計算 |

- 【口頭】[▶ 1:03:00](https://youtu.be/36S3yCY193M?t=3780) 景觀不會變很快，所以前幾步梯度很小的參數，接下來幾步多半還是小。
- 剪枝視窗結束後回到累積視窗，因為景觀可能變了。
- 例子：累積後 $\theta_2$、$\theta_4$ 很小 → 剪枝視窗只更新 $\theta_1$、$\theta_3$。既不用不可靠的梯度，也省下算 $\theta_2$、$\theta_4$ 梯度的成本。

**結果**：[▶ 1:03:00](https://youtu.be/36S3yCY193M?t=3780)

- 跟單純在量子電腦上訓練比，分類準確率提升。
- 【口頭】[▶ 1:04:00](https://youtu.be/36S3yCY193M?t=3840) 有時甚至**比在傳統模擬器上訓練還好**，因為它適應了真實硬體的雜訊。
- 【投影片補充】收斂加快，**訓練時間減半**。
- 損失：介於無雜訊的傳統訓練和單純量子訓練之間，縮小了差距。
- VQE 上也縮小了量子和傳統之間的差距。

⚠️ 待確認：[▶ 1:03:00](https://youtu.be/36S3yCY193M?t=3780) 準確率提升幅度，講者口頭說「約 10%」，投影片寫「2%～4%」。

**機率式 vs 確定式剪枝**：[▶ 1:06:00](https://youtu.be/36S3yCY193M?t=3960) 【口頭】機率式比確定式好約 3%～7%。

### 6.4 可擴充性

[▶ 1:05:00](https://youtu.be/36S3yCY193M?t=3900)

| | 傳統模擬 | 晶片上訓練 |
|---|---|---|
| 成本隨量子位元數 | **指數成長**，超過約 30 個量子位元就非常陡 | **線性**（記憶體就是量子暫存器的數量） |

## 7. TorchQuantum

[▶ 1:06:00](https://youtu.be/36S3yCY193M?t=3960)

【口頭】好的基礎設施對探索量子機器學習（編碼、電路、剪枝、最佳化器……）非常關鍵。

**特色**：

| 功能 | 說明 |
|---|---|
| **PyTorch 原生** | [▶ 1:07:00](https://youtu.be/36S3yCY193M?t=4020) 所有運算都用 PyTorch 的運算和資料結構實作 |
| **GPU 加速** | 支援批次模式 |
| **自動梯度** | PyTorch 的最佳化器直接拿來用 |
| **模擬器** | 狀態向量和密度矩陣 |
| **動態計算圖** | [▶ 1:08:00](https://youtu.be/36S3yCY193M?t=4080) 【口頭】像 PyTorch vs TensorFlow 1：很多量子函式庫是靜態圖，TorchQuantum 每做一個操作就能檢查目前狀態，**方便除錯** |
| **閘層級和脈衝層級** | [▶ 1:09:00](https://youtu.be/36S3yCY193M?t=4140) 脈衝層級要解 Schrödinger 方程式、Lindblad master equation，也有 GPU 加速 |
| **轉換器** | 一鍵轉成能在 **IBM Qiskit** 上跑的電路 |
| **雜訊感知訓練** | 已整合 |

【口頭】[▶ 1:08:00](https://youtu.be/36S3yCY193M?t=4080) 已經有約 50 篇論文用 TorchQuantum 發表。

**用 TorchQuantum 寫量子神經網路**：[▶ 1:10:00](https://youtu.be/36S3yCY193M?t=4200)

結構跟寫 PyTorch 模型幾乎一樣：

1. `import torchquantum as tq`、`import torchquantum.functional as tqf`。
2. 模型繼承 `tq.QuantumModule`。
3. `__init__`：指定量子位元數、編碼器（例如旋轉閘編碼）、可訓練的閘（例如 RX、CRX）、測量方式。
4. [▶ 1:11:00](https://youtu.be/36S3yCY193M?t=4260) `forward`：降採樣影像 → 重設量子狀態 → 編碼 → 可訓練的閘 → 不可訓練的閘（H、CNOT、自訂的么正矩陣）→ 測量。
5. 測量出來是**普通的 PyTorch tensor**，後面可以接任何層（甚至 Transformer、softmax）。

## 8. 一頁速查表

### 8.1 中性原子

| 項目 | 一句話 |
|---|---|
| **SLM / AOD** | SLM 固定原子；AOD 原子可整列整行移動 |
| **Raman / Rydberg 雷射** | 單量子位元閘個別照射；兩量子位元閘全域照射（高平行度、強制執行） |
| **Q-Pilot** | 用 CNOT 扇出做「飛行輔助位元」：建立 → 做閘 → 回收 |

### 8.2 PQC 與編碼

| 項目 | 公式或做法 | 關鍵一步 |
|---|---|---|
| **表達力** | 跟均勻分布的 KL 散度 | $H$+$R_Z$ 只涵蓋一圈；加 $R_X$ 涵蓋整顆球 |
| **糾纏能力** | Meyer-Wallach 量度 $\in[0,1]$ | 量子位元之間沒閘 → 0 |
| **基底編碼** | $x=2\to\vert10\rangle$ | 可疊加同時編多個數 |
| **振幅編碼** | 資料當振幅，要正規化 | $N$ 個特徵只要 $\log_2N$ 個量子位元 |
| **角度編碼** | $R_Y(x_i)$ | 資料當旋轉角 |

### 8.3 訓練

| 方法 | 公式 | 量子電腦上跑幾次 |
|---|---|---|
| **有限差分** | $\dfrac{f(\theta+\epsilon) - f(\theta-\epsilon)}{2\epsilon}$ | $2N$，近似 |
| **Parameter-shift** | $\dfrac{1}{2}\left[f(\theta+\frac{\pi}{2}) - f(\theta-\frac{\pi}{2})\right]$ | $2N$，**精確** |
| **反向傳播** | — | 只能在模擬器 |
| **SPSA** | 同時擾動所有參數 | **2 次** |
| **混合訓練** | $\dfrac{\partial L}{\partial\theta_i} = \sum_j\dfrac{\partial L}{\partial f_j}\dfrac{\partial f_j}{\partial\theta_i}$ | 量子只做前向 |

關鍵一步（parameter-shift）：$f = a\cos\theta + b\sin\theta + c$ 時，平移 $\pm\frac{\pi}{2}$ 把 $\cos$、$\sin$ 互換，相減除以 2 剛好是導數。

### 8.4 雜訊感知訓練

| 項目 | 一句話 |
|---|---|
| **觀察** | 雜訊大小固定 → 小梯度的相對誤差很大 |
| **機率式梯度剪枝** | 累積視窗記錄梯度大小 → 剪枝視窗依機率跳過小梯度 |
| **好處** | 更可靠、更省計算；訓練時間減半 |
| **貧瘠高原** | 梯度變異數隨量子位元數指數下降 |

### 8.5 ⭐ 關鍵數字

| 數字 | 是什麼 |
|---|---|
| **約 1,200 / 1,100** | Atom Computing 機器的量子位元數 / 可用數 |
